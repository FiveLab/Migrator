Security Policy
===============

Supported Versions
------------------

Security fixes are provided for the latest released `1.x` version. Please make sure you run the
most recent release before reporting an issue.

Reporting a Vulnerability
-------------------------

Please **do not** report security vulnerabilities through public GitHub issues or pull requests.

Instead, report them privately in one of the following ways:

* Use GitHub's **"Report a vulnerability"** button on the repository's *Security* tab
  (Security advisories), or
* Email **dev@fivelab.org** with a description of the issue and, if possible, a minimal
  reproduction.

We will acknowledge your report as soon as possible and keep you informed about the progress of
the fix. Once a fix is released, we will credit the reporter unless anonymity is requested.
